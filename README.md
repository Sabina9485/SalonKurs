# 💅 Aura Studio — мобильный CRM для салона красоты

**Aura Studio** — это Android-приложение для автоматизации работы салона красоты. Оно объединяет в себе базу клиентов, расписание мастеров, прайс-лист услуг и систему онлайн-записи на приём.

Приложение написано на **Kotlin** с использованием современного декларативного UI (**Jetpack Compose**) и локальной базы данных **Room**.

---

## 🎥 Демонстрация работы

В папке [`/demo`](./demo) находится видеофайл **`demo.mp4`**, в котором показан пользовательский путь: от приветственного экрана и главной панели до создания новой записи с выбором мастера, услуги и времени.

## 🛠 Стек технологий

| Компонент | Технология |
| :--- | :--- |
| **Язык** | Kotlin |
| **UI / Дизайн** | Jetpack Compose, Material 3, кастомная тема «Aura» (градиенты, карточки, аватары) |

| **Сборка** | Gradle (Kotlin DSL) |

## ✨ Особенности реализации

1. **Умное расписание и слоты времени**:
   В форме записи реализован выбор времени по слотам (с 9:00 до 20:00 с шагом 30 минут). Мастер и услуга выбираются в виде горизонтальных карточек с аватарами и ценами.

2. **Строгая целостность данных (CASCADE)**:
   В базе данных настроены внешние ключи (Foreign Keys) с параметром `onDelete = CASCADE`. Если вы удаляете мастера или услугу, все связанные с ними записи на приём удаляются автоматически, что предотвращает появление «битых» данных в расписании.

3. **JOIN-запросы для быстрого UI**:
   Вместо загрузки ID и последующего поиска имен, DAO использует сложные SQL-запросы с `INNER JOIN` (например, `AppointmentDao.getAllDetailed()`). Это позволяет сразу получать готовые объекты с именами клиентов, мастеров и названиями услуг для отображения в списках.

4. **Кастомный дизайн «Aura»**:
   Приложение имеет собственный визуальный стиль: градиентные шапки экранов, скругленные карточки (Petal), цветные аватары с инициалами (генерируются автоматически на основе хеша имени), а также кастомные нижние панели навигации.
